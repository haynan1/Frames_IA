# Contribuir

Comece pelo README e pelas decisões de arquitetura. Use mudanças pequenas, uma intenção clara e fontes primárias para afirmações sobre ferramentas. Preserve os caminhos relativos para GitHub Pages.

Antes de enviar: execute `npm run check`, revise desktop e celular, teste o fluxo alterado com teclado e registre a validação. Não acrescente dependências para tarefas resolvidas pela plataforma sem justificar o benefício.

Conteúdo: explicar com exemplos próprios, identificar imagens de IA, registrar fontes e data. Não publicar PDFs de terceiros, dados de clientes, segredos ou referências privadas. Separe resultados medidos de hipóteses e promessas de fabricantes.

Um novo estudo visual deve incluir prompt, ferramenta, finalidade, limites observados e a imagem otimizada. Um novo modelo precisa de nome oficial, categoria, fonte, data e limitações. Não editar manualmente o guia gerado em `docs/GUIA.md`.
